# Sonnet 4.6 Bench

**Atenção:** O Claude possui um filtro de segurança no chat que pode bloquear o prompt longo. 

## Como usar:
1. Crie um **Project** no Claude.
2. Vá em `Instruções do projeto` (Project Instructions).
3. Cole o conteúdo do `prompt.txt` lá dentro.
4. Inicie um chat novo dentro desse projeto.
5. Mude o modelo para Sonnet 4.6 ou Haiku 4.5
6. Pronto, a bancada estará armada.
