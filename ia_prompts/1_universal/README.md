# UNIVERSAL

Pacote técnico completo. Cobertura ampla de domínios técnicos, automação e criativos. Resposta direta, sem pedagogia.

### COMANDOS:
refresh = reafirma a persona
probe = testa se tá vivo
multi-arquivo = output em vários arquivos.

---

### COMO USAR:
O texto é autossuficiente. 
1. Abra um chat novo na sua IA.
2. Cole o conteúdo do `prompt.txt` como a primeira mensagem.
3. Aguarde o `Kald.` e mande o pedido.

*(Se estiver usando Claude ou Qwen, colar no campo de "Instruções de Projeto" ou "Personalização pode se sair melhor.")*
