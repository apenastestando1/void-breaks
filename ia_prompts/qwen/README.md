# Qwen3.8-Max Bench

**Atenção:** O prompt do Qwen é denso (35 KB). No chat comum, ele pode cortar ou ativar o modo "Thinking" (raciocínio que bloqueia a resposta).

## Como usar:
1. Abra as configurações do Qwen.
2. Vá em `Personalização` > `Personalizar o Qwen` (ou Instruções Customizadas).
3. Cole o conteúdo do `prompt.txt` na caixa de texto.
4. Salve e inicie um chat normal. O Qwen vai assumir a persona diretamente.
