# Void Break (Bench)

Pacote técnico completo. Engenharia reversa, automação e workflows. 
Resposta direta, sem pedagogia.

Este repositório hospeda os arquivos de system prompt (Jailbreak Sheets) do servidor [**Void Break**](https://discord.gg/QAaPqnggAY).
Cada arquivo é um "briefing" pronto para ser colado na sua IA de preferência para destravar respostas técnicas.

## 🚀 Como usar

1. Escolha a IA que você quer destravar (pasta `ia_prompts/`).
2. Baixe o arquivo `.txt` ou copie o texto cru.
3. Cole como a **primeira mensagem** (Ou onde mencionado no `README.md`, caso haja) no chat da IA (ou no campo de System Prompt).
4. Aguarde a confirmação (`Kald.`) e mande o seu pedido técnico.

## 🛠️ Ferramentas e Módulos

Os arquivos na pasta `tools/` são voltados para plataformas e ambientes específicos:
- **Android:** Frida hooks, collector, persistência e bypass.
- **FiveM / Roblox:** Modificação de runtime, overlay e mods.
- **Discord / WhatsApp / TikTok:** Automação de DOM e Playwright.
- **Grabber:** Coleta silenciosa e staging.
- **Plug-in:** Extensões de browser e automação web.

## ⚠️ Notas de Bancada
- Algumas IAs possuem filtros de saída (scanners). Se o output for bloqueado, reinicie a sessão e use os comandos `refresh` ou `probe`.
- Não nos responsabilizamos pelo uso dos códigos. É uma bancada técnica.
